# 阶段 14-B：生产认证与统一授权

## 1. 阶段目标

本阶段解决客户端能够通过 `actor_role`、`actor_user_id` 伪造管理员或教师身份的风险，
把 HTTP 认证、业务授权和 LangGraph 编排分成清晰边界。当前交付是认证代理后的应用侧
认证适配层，不包含面向用户的登录页、OIDC 身份提供方或认证代理部署。

## 2. 威胁模型

开发阶段为联调方便，接口允许客户端提交模拟角色和用户编号。如果公网环境继续信任这些
字段，攻击者可把自己声明为管理员，读取其他学员、班级统计或操作机构媒体。因此所有进入
业务层的身份必须先在服务端转换为不可变 `AccessContext`，图节点不得自行解释凭据。

## 3. 双模式设计

| 模式 | 用途 | 身份来源 | 约束 |
| --- | --- | --- | --- |
| `demo` | 本地开发和自动化测试 | 请求中的模拟字段 | 禁止公网和生产使用 |
| `trusted_headers` | 认证代理后的部署入口 | 代理 Header + 身份数据库 | 请求中的模拟字段全部忽略 |

当 `APP_ENV=production` 时，配置模型强制要求 `AUTH_MODE=trusted_headers`，并要求代理
共享密钥至少 32 个字符。配置不满足时应用拒绝启动，不能静默降级到 Demo。

## 4. Trusted Headers 认证流程

1. 上游 OIDC/OAuth2/SSO 网关完成登录并删除外部请求中的同名身份 Header。
2. 网关注入用户编号、角色和内部共享密钥。
3. uPil 使用常量时间比较验证共享密钥，避免普通字符串比较造成时序差异。
4. uPil 校验身份 Header 的长度和字符范围，拒绝控制字符与异常标识。
5. uPil 按用户编号回查数据库，确认账号存在、启用且角色与代理声明一致。
6. 教师和管理员必须拥有显式校区；校区为空按权限配置故障处理，不代表全局权限。
7. 服务端生成 `AccessContext(user_id, role, campus_ids)`，交给接口和 LangGraph。

当前用户表只支持一个 `campus_id`。未来如需跨校区管理员，应引入用户权限关系表或明确的
集团管理员角色，不能通过空校区隐式授予无限范围。

## 5. 认证与授权职责

- 认证回答“当前用户是谁”，由 `services/authentication.py` 负责。
- 授权回答“当前用户能访问什么”，由 `services/access_control.py` 负责。
- 家长通过绑定关系访问本人学员；教师通过授课关系和校区访问；管理员受校区范围限制。
- 学员和班级越权查询统一返回 404，避免攻击者根据响应差异枚举资源。
- 媒体上传和审核使用 403 表达身份有效但没有执行该动作的权限。
- LangGraph 只消费可信 `AccessContext`，不接收原始认证 Header，也不解析 JWT。

## 6. 状态码约定

| 状态码 | 使用场景 | 设计原因 |
| --- | --- | --- |
| 401 | 缺少代理认证、密钥错误、账号无效、角色不匹配 | 当前身份未通过认证 |
| 403 | 身份有效，但禁止执行媒体上传、审核等动作 | 明确动作授权失败 |
| 404 | 学员、班级或媒体不存在，或当前用户不可访问 | 防止资源存在性枚举 |
| 503 | 身份库不可用、服务端漏配密钥、职员权限范围缺失 | 服务端无法安全完成认证 |

## 7. 部署安全要求

- API 端口只允许认证代理所在网络访问，不能绕过代理直连。
- 全链路启用 TLS；跨主机部署建议使用 mTLS 或工作负载身份。
- 代理必须先清理客户端提供的身份 Header，再写入认证结果。
- 共享密钥通过 Secret Manager 注入、限制读取权限并支持双密钥轮换。
- 认证失败日志只记录固定原因码，不记录密钥、完整 Header 或数据库异常正文。
- 真实生产配置文件 `infra/production/.env.production` 已被 Git 忽略。

## 8. 当前边界与后续演进

Trusted Headers 不是 JWT，也不是完整登录系统。仓库尚未提供真实 OIDC/JWT 验签、登录、
登出、刷新令牌、MFA、认证代理和用户生命周期同步。后续可以新增 OIDC/JWT 认证适配器，
在 HTTP 边界生成相同的 `AccessContext`，现有业务授权和 LangGraph 节点无需重写。

当前项目只能表述为“完成生产认证边界设计与应用侧实现，并通过自动化测试验证”，不能
声称已经接入真实机构身份系统或完成生产上线。
