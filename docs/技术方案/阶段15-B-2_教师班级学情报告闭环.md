# 阶段 15-B-2：教师班级学情报告闭环

## 1. 目标与范围

教师可在班级学情页用自然语言指定周期，生成、查看并下载自己实际授课班级的 PDF。统计值由数据库确定性计算，统一学情分析 Agent 内部的班级报告处理器只负责组织展示。

本阶段不增加 CSV、Markdown 下载、起止日期控件、阈值控件或格式选择。当前版本已移除 A2A/DSH 运行链路。教师低课时规则固定为剩余课时不超过 5 节，课程继续使用现有舞蹈、美术、音乐和少儿编程数据。

## 2. 接口

~~~text
POST /api/v1/classes/{class_id}/reports
GET  /api/v1/classes/{class_id}/reports
GET  /api/v1/reports/{task_id}
GET  /api/v1/reports/{task_id}/download
~~~

生成请求只接受：

~~~json
{"period": "最近30天"}
~~~

页面默认“最近30天”，也支持“上个月”“本月”“2026年8月”和明确自然语言日期范围。浏览器不解析周期，只使用后端返回的权威日期显示统计与历史记录。

## 3. 执行链路

~~~text
教师点击“生成班级报告”
  -> 服务端认证教师
  -> 当前校区和授课关系校验
  -> 自然语言解析为权威日期范围
  -> 数据库计算 ClassLearningSummary
  -> 统一学情分析 Agent 调用班级报告处理器生成受控 Markdown
  -> 权威字段逐项交叉校验
  -> 共享 WeasyPrint 转换器生成 PDF
  -> pypdf 复核完整性与内部 ID
  -> MinIO 私有桶上传
  -> 保存唯一 PDF Artifact 元数据
  -> 教师重新鉴权后由 FastAPI 代理下载
~~~

教师与家长共用 `backend/app/services/report_execution.py`、`backend/app/services/markdown_pdf.py`、报告状态机、MinIO 上传和下载代理。差异只在资源授权、权威快照与 Markdown 字段契约，避免复制家长报告的事务和安全逻辑。统一 Agent 内部按个人摘要、家长报告和班级统计处理器划分职责。

## 4. 确定性统计

`query_class_learning_summary()` 在主数据库内计算：

- 有效报名学员数和周期内计划课次；
- 完课率、应登记与已登记考勤；
- 出勤、缺勤、请假、未登记和出勤率；
- 缺勤 TOP5；
- 剩余课时不超过 5 节的学员；
- 缺失课时账户数量。

模板输出的课程、周期和以上数字必须与 `ClassLearningSummary` 完全一致。班级 ID 与学员 ID 不进入 Markdown 或 PDF，缺勤排行使用“学员-01”等展示别名。任一数字异常，任务失败且不展示半成品。

## 5. 授权与隐私

生成前使用教师当前校区和授课关系校验班级；列表 SQL 同时限定请求人、`teacher_class_learning_report` 类型和班级；详情与下载再次检查当前授课关系。教师调离班级后，即使知道旧任务 ID 也无法继续读取。

其他教师、其他校区、关系已撤销或不存在的报告统一按不可访问资源处理。响应不包含请求人、scope、原始班级 ID、学员 ID、对象键、桶名、MinIO 端点、Token 或底层异常。

## 6. 单 PDF、幂等与失败处理

新教师任务只有一个 PDF Artifact，不落库 Markdown，也不生成 CSV。相同教师、班级、解析后周期、任务类型和模板版本复用同一 pending、running 或 completed 任务。数据库条件更新确保只有一个请求取得执行权，避免重复统计、渲染和上传。

失败任务是不可变终态，重新点击会创建带 `_a2` 等后缀的新尝试。上传成功但数据库提交失败时尽力删除对象；下载前再次校验 SHA-256、大小、页数、标题、模板版本和内部 ID。

## 7. 前端职责

班级学情页提供班级编号、自然语言周期、“生成班级报告”和“刷新历史”。生成后显示权威统计、历史任务状态和详情入口；详情页复用统一安全下载组件，并根据任务类型显示教师授课关系说明。

按钮补足稳定任务入口、失败重试、历史回看和文件下载，不实现第二套 Agent。聊天仍承担自由意图交互，页面只调用同一统一学情分析 Agent 报告执行链。

## 8. 暂缓项

阶段 15-A-3 保持“生产增强，暂缓”：不实现队列 worker、任务租约、撤回、保留期、对象对账和自动补偿重试。生产部署仍需单独验证真实 OIDC、PostgreSQL、MinIO 私有桶、TLS、Secret 和容量。

## 9. 结论

教师班级报告形成“当前授课授权 -> 确定性统计 -> 本地固定模板 -> 单 PDF 私有交付”的完整闭环，并复用家长报告基础设施。统一 Agent 仍保持个人、家长和班级处理器的职责边界。
