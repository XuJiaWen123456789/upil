# uPil 答辩与面试问答索引

按项目阶段组织。每个问题都对应项目中真实做过的决策或踩过的坑，可直接用于答辩预演和技术面试。

## 文件清单

| 文件 | 对应阶段 | 核心考点 |
|---|---|---|
| 阶段0_需求与技术选型.md | 需求收敛、技术选型 | MVP 划分、LangChain/LangGraph、SSE、RAGFlow、Deep Agents 评估 |
| 阶段1_项目骨架与环境.md | FastAPI + SSE + LangGraph 骨架 | Python 3.11、SSE 协议、编码踩坑、测试策略 |
| 技术专项_A2A与DSH.md | A2A 协议、DSH 编码智能体 | 协议选型理由、模板化执行、安全边界 |

## 使用建议

1. 答辩前重点背熟每个文件中标有【高频】的问题；
2. 面试中被追问时，先给结论，再给理由，最后给取舍（"我们没有做什么"往往比"我们做了什么"更加分）；
3. 后续阶段完成后再追加：数据库设计、RAG 实战、前端、部署、审计安全等专项。

## 通用答题结构（STAR 变体）

    结论先行：一句话回答选型/做法
    场景约束：项目面临什么限制
    备选对比：当时考虑过哪些方案
    取舍说明：为什么最终选这个，放弃了什么
    边界意识：这个方案不适用什么场景
