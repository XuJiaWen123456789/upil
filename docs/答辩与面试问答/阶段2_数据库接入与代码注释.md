## 遇到问题

第一次接入数据库后，两个 API 测试返回“学情数据服务暂时不可用”。单独调用数据库服务正常，因此问题不在 SQL 查询和权限逻辑，而在测试环境的 SQLite 内存连接。

SQLite 的 :memory: 数据库默认按连接隔离。FastAPI TestClient 可能在不同线程使用另一条连接，于是请求线程看到的是没有建表的空数据库，最终触发数据库异常。

## 解决方案

测试数据库使用 StaticPool，并允许测试请求线程复用数据库连接。该配置只用于测试，不改变正式 PostgreSQL 的连接池配置。
