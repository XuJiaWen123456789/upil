# 阶段 15-A-2：家长报告 PDF 与私有下载面试问答

## Q1：为什么不让模型或远程服务直接交付 PDF？

**答：** 当前报告在同进程由统一学情分析 Agent 的家长报告处理器使用脱敏权威快照和固定模板生成 Markdown。主系统负责数字事实、对象存储和下载鉴权，模板不会改写统计口径，也不允许外部资源。报告链路不需要动态代码执行或独立 DSH 服务。

## Q2：为什么从 ReportLab 改成 markdown-it-py + WeasyPrint？

**答：** 需求不要求复杂固定版式，手写 ReportLab 段落、分页和字体代码成本过高。共享转换器用 markdown-it-py 做 token 白名单，WeasyPrint 负责成熟的 HTML/CSS 排版，pypdf 负责输出复核；家长和教师都能复用，同时保留安全边界。

## Q3：通用 Markdown 转 PDF 会不会扩大攻击面？

**答：** 项目没有直接执行通用 CLI。Markdown 禁止 HTML、链接、图片、代码块和 URL，HTML 模板动态值转义，WeasyPrint 资源加载器拒绝网络及任意文件，只放行配置的本地字体。渲染结果还要再次检查文本和敏感值。

## Q4：为什么新任务不保存 Markdown？

**答：** Markdown 只是固定模板到 PDF 转换器之间的受控内存中间表达。用户最终只需要 PDF，把 Markdown 落库会增加敏感正文、完整性和双产物一致性成本。新任务只保存一个 PDF Artifact 元数据，Markdown 生命周期限定在当前请求内存。

## Q5：历史 Markdown 和双产物怎么办？

**答：** 读取路径兼容阶段 15-A-1 的单 Markdown，以及旧 15-A-2 的 Markdown + PDF。旧双产物先验证 Markdown 再返回 PDF；新写入路径仍严格限制为唯一 PDF，兼容逻辑不会反向扩大现行契约。

## Q6：如何防止报告改写统计数字？

**答：** 周期、出勤、请假、缺勤、出勤率、已完成课时、剩余课时、课程概览和已发布进度都直接来自 `LearningReportSnapshot`。模板不计算、不改写数字，渲染前后均做完整性和敏感信息检查。

## Q7：中文字体如何保证？

**答：** 字体路径显式配置且必须存在。WeasyPrint 使用 Noto CJK 本地字体，缺字体或 Pango/Cairo 运行库时失败关闭，不静默回退。Linux 容器专项强制真实渲染，pypdf 再验证中文标题和正文可提取。

## Q8：为什么模板版本升级为 v2？

**答：** `learning-report-pdf-v1` 对应历史 ReportLab 实现，`learning-report-pdf-v2` 对应当前共享 WeasyPrint 转换器。模板版本参与幂等业务键，升级可避免两种渲染器错误复用同一个 completed 任务。

## Q9：为什么 PDF 不存 PostgreSQL？

**答：** 大二进制会扩大数据库备份、复制、事务日志和查询内存成本。MinIO 保存文件字节，PostgreSQL 只保存对象键、SHA-256、媒体类型、文件名、大小、页数和业务所有权。

## Q10：为什么不用预签名 URL？

**答：** FastAPI 代理下载可在每次请求重新检查登录身份、当前学员绑定、任务类型和文件完整性。浏览器永远看不到对象键、桶名、MinIO 地址或可转发 URL，解绑后权限也能立即撤销。

## Q11：上传后数据库失败怎么办？

**答：** 当前采用先上传、再提交元数据；提交失败时回滚并尽力删除对象。这不是严格分布式事务。outbox、自动补偿重试和定期对账属于阶段 15-A-3，已明确标记为“生产增强，暂缓”。

## Q12：如何避免相同报告重复生成？

**答：** 请求人、学员匿名引用、解析后周期、任务类型和模板版本形成稳定键。数据库条件更新保证只有一个并发请求领取 pending 任务；running 或 completed 直接复用，避免重复统计、渲染和上传。失败后创建新尝试，不复活旧终态。

## Q13：显式按钮会不会违背意图识别业务？

**答：** 不会。聊天仍是自然意图入口，按钮解决正式产物的可发现性、任务状态、失败重试、历史回看和下载。两者最终调用同一个 `report_execution.py`，没有复制统计或 PDF 逻辑。

## Q14：为什么页面不提供开始和结束日期？

**答：** 页面只提供默认“最近30天”的自然语言输入，用户可改为“上个月”或明确月份。后端统一解析并校验日期，浏览器不能直接提交起止日期，因此避免双套周期状态和客户端越权扩大统计范围。

## Q15：如何准确写进简历？

**答：** 可以写：设计家长学情报告私有交付链路，以数据库确定性快照和本地固定模板生成受控 Markdown，通过 markdown-it-py、WeasyPrint 和 pypdf 生成及复核中文 PDF，使用 MinIO 私有桶、单 Artifact 元数据、幂等执行、失败补偿和动态所有权代理下载，避免内部标识及存储地址泄漏。
