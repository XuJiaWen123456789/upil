# 阶段 15-B-2：教师班级学情报告闭环面试问答

## Q1：教师报告是否复制了家长报告代码？

**答：** 没有。两个入口共用 `report_execution.py` 的任务领取、确定性快照、PDF 转换、MinIO 上传、单 Artifact 持久化、幂等和失败补偿。教师只新增班级授权、班级权威快照和字段校验薄层；统一学情分析 Agent 内部按处理器区分个人、家长和班级场景。

## Q2：为什么统计值不能由 LLM 计算？

**答：** 完课率、出勤率、缺勤 TOP5、低课时和缺失账户属于可审计业务事实。后端从数据库确定性计算，本地固定模板只组织展示；渲染前逐项对照 `ClassLearningSummary`，任何异常都失败关闭。

## Q3：为什么页面只有自然语言周期？

**答：** 项目核心是意图驱动的多 Agent 体验。一个默认“最近30天”的自然语言输入既保持对话语义，也能覆盖“上个月”“本月”“2026年8月”等需求。起止日期控件会制造重复状态和额外校验面，浏览器也不应自行决定权威统计范围。

## Q4：为什么仍然需要“生成班级报告”按钮？

**答：** 聊天适合探索性提问，正式报告还需要稳定发起、任务状态、失败重试、历史回看和下载。按钮只提供可发现入口，最终仍调用同一统一学情分析 Agent 报告链，因此不等于新增后台报表子系统。

## Q5：教师如何被限制在自己的班级？

**答：** 生成前校验当前教师、校区和授课关系；列表把请求人、任务类型和班级下推到 SQL；详情与下载再次按最新授课关系授权。调离班级后，旧任务也会立即不可见。

## Q6：为什么低课时阈值不能由页面设置？

**答：** 阈值属于机构统计口径而非展示偏好。当前固定为剩余课时不超过 5 节，统一由后端传给统计函数，并写入报告字段契约，避免不同教师生成不可比较的结果。

## Q7：为什么取消 CSV 和 Markdown 下载？

**答：** 当前验收目标是可阅读、可打印的学情报告。多格式会增加产物一致性、权限、下载和测试分支，却没有明确用户价值。新任务只保存 PDF，Markdown 仅为请求内存中的受控中间态。

## Q8：如何避免重复生成？

**答：** 教师、班级、解析后周期、任务类型和模板版本构成稳定业务键。pending 任务通过数据库条件更新原子领取；running 或 completed 任务直接复用，避免重复统计、渲染和上传。failed 是不可变终态，重新发起创建新尝试。

## Q9：报告失败为什么不展示 Markdown 半成品？

**答：** 模板输出只有经过字段校验、PDF 渲染、pypdf 复核、私有上传和元数据提交后才算完成。中途失败时任务进入 failed，页面不获得 Markdown，也不会出现下载入口。

## Q10：PDF 如何避免内部 ID 泄漏？

**答：** 生成模板的班级数据只使用展示字段，缺勤排行使用匿名序号。转换器和下载边界都检查原始班级 ID、全部学员 ID、Token 和服务地址；详情 API 也不返回 scope 或对象存储元数据。

## Q11：为什么通过 FastAPI 下载而不是 MinIO 预签名 URL？

**答：** 代理下载可在每次请求重新校验教师当前授课关系、任务类型和 PDF 完整性，并写最小审计。浏览器看不到对象键、桶名和存储端点，授权撤销可以立即生效。

## Q12：如何准确描述这个阶段？

**答：** 可以表述为：复用家长报告安全交付基础设施，实现教师授课班级的确定性统计、本地固定模板、自然语言周期、单 PDF 私有存储和动态授权下载；当前运行链路不包含 A2A/DSH，真实基础设施仍需按部署环境联调。
