# uPil FAQ 知识资源包

## 资源定位

本目录是 uPil FAQ 知识问答智能体的知识资源包，当前使用“星河素质教育中心”作为虚构演示机构。所有文档仅用于开发、测试、答辩演示和 RAGFlow 导入验证，不代表任何真实机构政策。

真实项目上线前，需要由机构业务负责人审核并替换以下内容：课程信息、校区信息、收费标准、退费规则、请假补课规则、活动通知和客服联系方式。

## 文档使用约定

- 文档标题表达一个相对完整的业务主题，便于 RAGFlow 分块后保留上下文。
- 规则类内容使用“适用范围、办理条件、办理步骤、例外情况”的顺序书写。
- 所有金额、日期、联系方式和政策均为演示值，真实资料替换时应重新审核。
- 不将学员姓名、手机号、身份证号、家庭住址等个人信息放入 FAQ 知识库。
- 涉及具体学员的课时、出勤和缴费余额，必须由 uPil 结构化数据库和权限服务处理，不能依赖本知识库。
- 特殊情况规则只说明处理边界和申请流程；延期结果、退费金额、转校区结果和投诉责任结论必须由有权限岗位审核。
- 受伤、严重过敏和其他紧急健康问题优先由现场工作人员和当地紧急服务处置，不能等待在线客服完成普通问答流程。

## 推荐导入方式

1. 在 RAGFlow 创建两个独立知识库：`uPil-课程与公开咨询知识库` 和 `uPil-服务规则与异常处置知识库`。
2. 将 `ragflow_import/01_public_consultation` 下的公开资料导入课程与公开咨询库，将 `ragflow_import/02_service_rules` 下的规则资料导入服务规则库。
3. 两个 Dataset 均先按 `General / 256 / Overlap 0 / Ollama bge-m3` 做小批量解析和抽查，再逐步导入剩余文件。
4. 文档解析完成后，使用 `evaluation/faq_eval_cases.jsonl` 和 `evaluation/edge_case_eval_cases.jsonl` 逐题验证；评测文件不上传到 Dataset。
4. 只有答案包含正确业务规则并能定位到来源文档，才认为该问题通过。
5. 正式上线前删除或隔离本演示知识库，避免演示规则进入生产环境。

## 特殊场景导入边界

09_exception_handling 属于权威规则资料，但它不提供任何真实学员的动态结果。建议在 RAGFlow 中保留其文档来源和版本信息；对于涉及具体订单、课时、出勤、班级名额和退款金额的问题，FAQ 智能体必须将规则检索结果交给学情分析工具或人工审核链路，不能仅凭文档生成具体数字。

evaluation 目录中的对抗样例和边界评测集不能上传到生产知识库。它们只用于验证拒答、人工升级、动态工具调用和隐私保护行为。
