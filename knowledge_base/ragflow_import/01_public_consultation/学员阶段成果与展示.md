# 学员阶段成果与展示

> 资料性质：虚构演示数据，仅用于星河素质教育中心知识库开发、测试和答辩演示，不代表真实机构政策。
>
> 资料版本：demo-2026-09-01

## 阶段反馈

星河素质教育中心重视过程反馈，每 8 至 12 次课为一个阶段，教师会结合课堂观察，向家长反馈以下内容：

- 出勤与课堂参与情况；
- 本阶段学习目标和完成情况；
- 孩子的进步表现和需要继续练习的内容；
- 下一阶段的学习建议；
- 需要家长配合的事项，例如课后练习或装备准备。

阶段反馈不是排名，也不对学员进行简单的好坏评价。家长如需更详细了解，可以预约教师或教务一对一面谈。

## 作品与展示

- 舞蹈课程：通过课堂小展示、节日汇演和开放日组合展示学习成果
- 美术课程：通过作品墙、绘画作品展和线上作品集展示作品
- 编程课程：通过项目展示会，由学员上台讲解自己的作品
- 音乐课程：通过合唱排练和演出展示学习成果

作品展示以鼓励为主，是否参加展示尊重学员和家长意愿。机构不会未经授权公开学员作品、照片或姓名。

## 家长开放日

机构不定期举办家长开放日，家长可以预约进入课堂观摩。开放日安排、人数限制和观摩规则以当期通知为准。日常课程通常不安排家长进入教室，以免影响课堂秩序。

## 学习报告示例

以下为虚构学员的简化学习报告示例：

| 项目 | 内容 |
|---|---|
| 学员 | 示例学员 |
| 课程 | 中国舞基础班 |
| 阶段 | 第 1 至 8 次课 |
| 课堂表现 | 能跟随完成基础律动，节奏感有进步 |
| 进步表现 | 体态更挺拔，敢于在小组前展示 |
| 继续练习 | 基本功软开度需要循序练习，不过度追求幅度 |
| 下阶段建议 | 继续保持每周 2 次课，按教师指导完成课后拉伸 |

上述报告为演示样式，真实学习报告以教务系统记录和教师反馈为准。

## 家长如何了解学习情况

1. 查看阶段反馈和学习报告；
2. 参加家长开放日或预约面谈；
3. 关注机构发布的汇演、作品展和项目展示通知；
4. 与任课教师或教务老师保持沟通。

家长不应仅以一次展示或一次比赛结果判断孩子的全部进步，持续投入和兴趣保持同样重要。
