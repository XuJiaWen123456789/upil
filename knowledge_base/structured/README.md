# 结构化学情演示数据

本目录保存学情分析智能体所需的结构化演示快照，不属于 FAQ 文档知识库，也不应上传到 RAGFlow 作为公开问答语料。

## 文件说明

| 文件 | 用途 | 生产替代来源 |
|---|---|---|
| progress_records.json | 学员阶段进度、优势、下一步重点和教师建议 | 教务系统或教学评价系统的只读接口 |

## 使用边界

- learner_id、课时、出勤和进度只允许在身份核验与权限检查通过后返回。
- progress_records.json 是脱敏演示数据，不能代表真实学员档案。
- 课时与出勤由数据库记录确定性计算，不能从 FAQ PDF 或大模型生成。
- 需要班级汇总、趋势分析或报表时，应先生成最小化数据快照，再交给受控分析任务。
- 未来接入 A2A 时，建议以 Pydantic 契约序列化快照，禁止将 ORM 对象或数据库连接传给远程节点。
